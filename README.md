# Temporal Fusion Transformer for Predictive Maintenance

This repository outlines an exploratory project on time-series modeling for remaining useful life prediction with the NASA C-MAPSS turbofan dataset.

## Project status

This repository currently contains a project overview, not a reproducible implementation. Model code, completed experiments, and validated results are not available here yet. No performance claims are made.

The project is separate from my current research interests in HCI, Information Systems, and human-AI interaction.
